# Contributing to skilld

Thank you for your interest in contributing to skilld!

## Project Structure

- `apps/backend` owns the FastAPI Python service.
- `apps/extension` owns the Manifest V3 browser extension.
- `apps/menubar` owns the macOS SwiftUI app.
- `packages/shared-types` owns TS interfaces shared across the monorepo.

## Getting Started

Please refer to the `README.md` in each respective app for local development instructions. 
Make sure to read `AGENTS.md` for AI agent rules.
